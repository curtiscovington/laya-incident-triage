# Publication notes — v0.1.0

This public repository was prepared after the controlled study completed.
The initial public Git commit is **not** the study's pre-evaluation timestamp.
The local protocol freeze and development selection are retained in their
original content-hashed form. No external preregistration is claimed.

Publication cleanup changed the repository landing page and added licensing,
dependency entry points, CI, and these notes. It did not modify any source, data,
prompt, environment record, or protocol covered by study/FREEZE.json. The
original local directory was named jev-incident-triage. The public repository is
named laya-incident-triage to identify the model actually tested.

The completed development and test predictions, selection, classifier and plots
are included. Model weights, installed packages, and transient progress logs are
excluded. Some raw runtime metadata retains the original local model path;
that is historical provenance, not a portable installation requirement.

The figure layout pass was added after numerical analysis. It reads the saved
measurements and changes only presentation. See study/artifacts/FIGURE_NOTE.md.

The original 20-case pilot remains documented and is excluded from the main
study metrics. The 576-record study is synthetic, template-based, and authored
with its oracle labels. Independent human label review remains outstanding.
No blog article is published by publishing this code repository.
